# Evidence images

Screenshots of the OpenRoad client, produced by the window gallery
(`SCENE=ui_testing UI_ONLY=<window>` plus the one-shot `SCREENSHOT=` capture).

They live on this orphan branch and in no commit of `main`: a screenshot of this
client is the user's own PK2 art, rendered, and the source tree stays free of
binaries. Pull requests link them by raw URL.
